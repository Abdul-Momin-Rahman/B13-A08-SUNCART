# 🛒 E-Commerce Product App

The name of the project is SunCart .A modern full-stack web application built with Next.js that allows users to browse products, view detailed product information, and manage authentication with secure login and registration.

---

## 🌐 Live Demo

👉 https://suncart-summer-essentials-store.vercel.app

---

## 🎯 Purpose

This project is built to demonstrate a real-world e-commerce flow including:
- Product browsing system
- Authentication (email + Google login)
- Protected routes
- User profile management
- Clean UI with modern design



---

## ✨ Key Features

- 🔐 Secure authentication (Email + Google OAuth)
- 👤 User profile page with avatar & details
- 🛍️ Dynamic product listing & product details page
- 🔒 Protected routes with middleware
- ↩️ Redirect back to previous page after login
- ⚡ Loading states and smooth UX
- 🎨 Modern UI styled with Tailwind CSS
- 📱 Fully responsive design
- 🧭 Clean routing using Next.js App Router
